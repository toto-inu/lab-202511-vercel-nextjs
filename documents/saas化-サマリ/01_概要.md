# SaaS化プロジェクト概要（サマリ版）

## 🎯 目的
シンプルなTodoアプリ → マルチテナントSaaS化

## 📋 主要機能

### 1. マルチテナント
- Tenant単位でデータ分離
- ユーザーは複数Tenant所属可能
- Tenant切り替えUI

### 2. 階層構造
```
Tenant > Project > Todo
```

### 3. 権限モデル（3階層）
```
Plan制限（システム）
  ↓
Tenant Role（OWNER/ADMIN/MEMBER）
  ↓
Project Role（ADMIN/EDITOR/VIEWER）
```

### 4. プラン
- **FREE**: 3プロジェクト、5ユーザー、100 Todo/プロジェクト
- **PRO**: 50プロジェクト、50ユーザー、1000 Todo、API、レポート
- **ENTERPRISE**: 無制限、カスタムロール、SSO、監査ログ

## 🔧 技術スタック
- **変更なし**: Next.js 16, Bun, PostgreSQL, Prisma, Clerk, Tailwind CSS
- **追加**: Next Admin（管理画面）

## 📅 実装フェーズ（4-6週間）
1. **Phase 1**: データモデル構築（1週間）
2. **Phase 2**: 認証・認可拡張（1週間）
3. **Phase 3**: コア機能実装（1-2週間）
4. **Phase 4**: 管理画面（1週間）
5. **Phase 5**: 既存機能移行（1週間）

## ⚠️ 重要な設計方針
- **データ分離**: すべてのクエリで`tenantId`必須
- **ロール管理**: DBで管理（Clerk metadataは使わない）
- **既存データ**: default Tenant/Projectに移行
- **後方互換**: 既存機能は動作し続ける
