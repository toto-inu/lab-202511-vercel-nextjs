## 🔔 エラーハンドリング

```typescript
try {
  await createTodo(projectId, data);
  toast.success('Todoを作成しました');
} catch (err) {
  if (err.message.includes('上限')) {
    setError(err.message);
    showUpgradeModal();  // アップグレード促進
  } else if (err.message.includes('権限')) {
    setError('権限がありません');
  } else {
    setError('予期しないエラー');
  }
  toast.error('作成に失敗');
}
```

### エラー対応表

| エラー | UI表示 | アクション |
|--------|--------|----------|
| プラン制限 | 警告バナー + アップグレードボタン | モーダル表示 |
| 権限不足 | エラーメッセージ | リロード促進 |
| ネットワーク | 再試行ボタン | リトライ処理 |

## ⏳ ローディング状態

- **ボタン**: スピナー + disabled
- **ページ遷移**: トップバープログレスバー
- **データ取得**: スケルトンUI

## 📱 レスポンシブ

- **モバイル(<768px)**: 1列、簡略表示
- **タブレット(768-1024px)**: 2列
- **デスクトップ(>1024px)**: 3列、サイドバー常時表示
