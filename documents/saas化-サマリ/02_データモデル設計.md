# データモデル設計（サマリ版）

## 📊 新規モデル

### Plan
```typescript
- FREE/PRO/ENTERPRISE
- 制限: maxProjects, maxUsersPerTenant, maxTodosPerProject
- 機能フラグ: JSON（apiAccess, advancedReporting等）
```

### Tenant
```typescript
- 組織・企業単位
- planId（FK to Plan）
- status: ACTIVE/TRIAL/SUSPENDED/CANCELLED
```

### TenantMember
```typescript
- User ↔ Tenant（N:M）
- role: OWNER/ADMIN/MEMBER
```

### Project
```typescript
- Tenant内の作業単位
- tenantId（FK to Tenant）
```

### ProjectMember
```typescript
- User ↔ Project（N:M）
- role: ADMIN/EDITOR/VIEWER
```

## 🔄 既存モデル拡張

### User
```diff
+ isGlobalAdmin: Boolean（システム管理者用）
- role Enum削除（TenantMember/ProjectMemberで管理）
```

### Todo
```diff
+ tenantId: String
+ projectId: String（FK to Project）
+ createdById: String（FK to User）
+ priority: Enum（LOW/MEDIUM/HIGH/URGENT）
```

## 🔑 重要なリレーション
```
Plan (1) → (N) Tenant
Tenant (1) → (N) Project
Tenant (N) ↔ (M) User (via TenantMember)
Project (N) ↔ (M) User (via ProjectMember)
Project (1) → (N) Todo
User (1) → (N) Todo (createdBy)
```

## 📝 移行メモ
1. 既存User.roleフィールドを削除
2. ADMIN → default TenantのOWNER
3. USER → default TenantのMEMBER
4. 既存Todo → default Project配下に移行
