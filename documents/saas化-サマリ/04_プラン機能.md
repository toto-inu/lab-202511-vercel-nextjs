# プラン機能（サマリ版）

## 💰 プラン一覧

### FREE（無料）
- プロジェクト: 3
- ユーザー: 5
- Todo: 100/プロジェクト
- 基本機能のみ

### PRO（¥2,900/月）
- プロジェクト: 50
- ユーザー: 50
- Todo: 1,000/プロジェクト
- **追加機能**: API、レポート、Webhooks、データエクスポート

### ENTERPRISE（カスタム）
- すべて無制限
- **追加機能**: カスタムロール、SSO、監査ログ、SLA保証、専任サポート

## 🔧 実装

### データベース
```typescript
model Plan {
  id: String
  name: "FREE" | "PRO" | "ENTERPRISE"
  maxProjects: Int?  // nullは無制限
  maxUsersPerTenant: Int?
  maxTodosPerProject: Int?
  features: Json  // 機能フラグ
}
```

### 制限チェック
```typescript
// リソース制限
const limitCheck = await checkResourceLimit(tenantId, 'projects');
if (!limitCheck.allowed) {
  throw new Error(`上限(${limitCheck.limit}個)に達しました`);
}

// 機能チェック
const plan = await getTenantPlan(tenantId);
if (!hasFeature(plan, 'apiAccess')) {
  throw new Error('APIは現在のプランでは利用できません');
}
```
