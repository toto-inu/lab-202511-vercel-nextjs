# 認証認可フロー（サマリ版）

## 🔑 ロール管理方針

**重要**: ロールは**データベース**で管理（Better Auth metadataは使わない）

- **Better Auth**: 認証のみ（ユーザーID、メール、プロフィール、セッション）
- **Database**: ロール・権限管理
  - TenantMember: Tenant Role
  - ProjectMember: Project Role
  - User.isGlobalAdmin: システム管理者

## 🔄 認証フロー

```typescript
// 1. Better Auth認証
const session = await auth.api.getSession({ headers: await headers() });

// 2. DB user取得/作成
let user = await prisma.user.findUnique({ where: { id: session.user.id } });
if (!user) {
  user = await createUserWithDefaultTenant(session.user);
}

// 3. 現在のTenant取得
const tenantId = await getCurrentTenantId(); // Cookie
const tenant = await getTenant(tenantId);
```

## 🏢 Tenant切り替え

```typescript
export async function switchTenant(tenantId: string) {
  const user = await getCurrentUser();

  // アクセス権チェック
  const membership = await prisma.tenantMember.findUnique({
    where: { userId_tenantId: { userId: user.id, tenantId } }
  });

  if (!membership) throw new Error('Access denied');

  // Cookieに保存
  await setCurrentTenantId(tenantId);
  revalidatePath('/');
}
```

## 🔧 Prisma Tenant分離

**推奨**: 明示的にtenantIdを指定

```typescript
await prisma.todo.findMany({
  where: {
    projectId,
    tenantId: tenant.id  // 明示的に指定
  }
});
```

**代替**: Prisma拡張（自動付与）

```typescript
const db = createTenantPrisma(tenant.id);
await db.todo.findMany({ where: { projectId } });
// tenantIdは自動で追加される
```
