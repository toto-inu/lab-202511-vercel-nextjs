# UI要件

## 概要

SaaS化に伴う新しいUI要件と既存UIの変更点。

## 1. Tenant切り替え

### ヘッダーコンポーネント

```
┌─────────────────────────────────────────┐
│ [Logo] [▼ Acme Corp] [Projects] [Users] │ <- グローバルヘッダー
└─────────────────────────────────────────┘
```

#### Tenant Switcher（ドロップダウン）

```
┌─────────────────────────┐
│ ✓ Acme Corp (Owner)     │ <- 現在のTenant
│   Personal (Member)      │
│   Startup XYZ (Admin)    │
├─────────────────────────┤
│ + 新しいTenantを作成     │
└─────────────────────────┘
```

**仕様**:
- ユーザーが所属する全Tenantを表示
- 各TenantにRole（Owner/Admin/Member）を表示
- クリックでTenant切り替え
- 切り替え後は自動リロード

**実装場所**: `components/TenantSwitcher.tsx`

```typescript
// components/TenantSwitcher.tsx
'use client'

export function TenantSwitcher({ tenants, currentTenantId }: Props) {
  const [open, setOpen] = useState(false);

  return (
    <DropdownMenu open={open} onOpenChange={setOpen}>
      <DropdownMenuTrigger>
        {currentTenant.name} <ChevronDown />
      </DropdownMenuTrigger>
      <DropdownMenuContent>
        {tenants.map(tenant => (
          <DropdownMenuItem
            key={tenant.id}
            onClick={() => handleSwitch(tenant.id)}
          >
            {tenant.id === currentTenantId && <Check />}
            {tenant.name}
            <span className="text-xs text-gray-500">({tenant.role})</span>
          </DropdownMenuItem>
        ))}
        <DropdownMenuSeparator />
        <DropdownMenuItem onClick={() => router.push('/tenants/new')}>
          <Plus /> 新しいTenantを作成
        </DropdownMenuItem>
      </DropdownMenuContent>
    </DropdownMenu>
  );
}
```

### レイアウト

```
┌─────────────────────────────────────────┐
│ プロジェクト                      [+ 新規] │
├─────────────────────────────────────────┤
│ ┌────────────┐  ┌────────────┐          │
│ │ Website    │  │ Mobile App │          │
│ │ 15 Todos   │  │ 23 Todos   │          │
│ │ 5 Members  │  │ 8 Members  │          │
│ └────────────┘  └────────────┘          │
│                                         │
│ ┌────────────┐                          │
│ │ Marketing  │                          │
│ │ 8 Todos    │                          │
│ │ 3 Members  │                          │
│ └────────────┘                          │
└─────────────────────────────────────────┘
```

**仕様**:
- グリッド表示（カードUI）
- 各カードにプロジェクト名、Todo数、メンバー数
- 新規作成ボタンは権限によって表示制御（OWNER/ADMIN）
- クリックでプロジェクト詳細へ遷移

**権限表示**:
- Project ADMIN: ⚙️ 設定アイコン表示
- Project EDITOR/VIEWER: アイコンなし

## 4. メンバー管理

### Tenantメンバー管理

```
┌─────────────────────────────────────────┐
│ メンバー管理                     [+ 招待] │
├─────────────────────────────────────────┤
│ Alice (alice@example.com)        OWNER  │
│ Bob (bob@example.com)            ADMIN  │
│ Charlie (charlie@example.com)    MEMBER │ [編集] [削除]
└─────────────────────────────────────────┘
```

**権限による制御**:
- OWNER: 全員のロール変更・削除可能
- ADMIN: MEMBER/ADMINのロール変更・削除可能（OWNER除く）
- MEMBER: 閲覧のみ

### Projectメンバー管理

プロジェクト設定内で管理。

```
┌─────────────────────────────────────────┐
│ プロジェクトメンバー            [+ 追加]  │
├─────────────────────────────────────────┤
│ Alice                            ADMIN  │
│ Bob                             EDITOR  │
│ Charlie                         VIEWER  │ [編集] [削除]
└─────────────────────────────────────────┘
```

**追加時**:
- Tenantメンバーから選択（ドロップダウン）
- ロール選択（ADMIN/EDITOR/VIEWER）

## 8. レスポンシブ対応

### モバイル（< 768px）

- Tenant Switcherをハンバーガーメニュー内に配置
- プロジェクト一覧を縦1列表示
- Todo一覧を簡略化（優先度などを省略）

### タブレット（768px - 1024px）

- プロジェクト一覧を2列表示
- サイドバーを折りたたみ可能に

### デスクトップ（> 1024px）

- 3列グリッド表示
- 常時サイドバー表示


### ローディング状態

- ボタン: スピナー表示 + disabled
- ページ遷移: トップバーにプログレスバー
- データ取得中: スケルトンUI

### エラーハンドリング

**Server Actionsとのやりとり**:

```typescript
// components/TodoForm.tsx
'use client'

import { createTodo } from '@/actions/todo';
import { useState } from 'react';

export function TodoForm({ projectId }: { projectId: string }) {
  const [isLoading, setIsLoading] = useState(false);
  const [error, setError] = useState<string | null>(null);

  async function handleSubmit(formData: FormData) {
    setIsLoading(true);
    setError(null);

    try {
      await createTodo(projectId, {
        title: formData.get('title') as string,
        description: formData.get('description') as string
      });

      // 成功時: トースト表示 + フォームリセット
      toast.success('Todoを作成しました');
      formRef.current?.reset();
    } catch (err) {
      // エラーハンドリング
      if (err instanceof Error) {
        if (err.message.includes('上限')) {
          // プラン制限エラー
          setError(err.message);
          // アップグレードプロンプトを表示
          showUpgradeModal();
        } else if (err.message.includes('権限')) {
          // 権限エラー
          setError('この操作を実行する権限がありません');
        } else {
          // その他のエラー
          setError('予期しないエラーが発生しました');
        }
      }

      toast.error('Todoの作成に失敗しました');
    } finally {
      setIsLoading(false);
    }
  }

  return (
    <form action={handleSubmit}>
      {error && (
        <div className="bg-red-50 border border-red-200 text-red-700 px-4 py-3 rounded">
          {error}
        </div>
      )}
      {/* フォームフィールド */}
      <button
        type="submit"
        disabled={isLoading}
        className="..."
      >
        {isLoading ? <Spinner /> : 'Todo作成'}
      </button>
    </form>
  );
}
```

**エラー種類と対応**:

| エラー | UI表示 | アクション |
|--------|--------|----------|
| プラン制限 | 警告バナー + アップグレードボタン | アップグレードモーダル表示 |
| 権限不足 | エラーメッセージ | ページリロード促進 |
| ネットワークエラー | 再試行ボタン | リトライ処理 |
| 一般エラー | エラーメッセージ | サポート連絡促進 |

**React Query / SWR（推奨）**:

Server Componentsを使用せず、クライアントでデータフェッチする場合:

```typescript
// hooks/useTodos.ts
import useSWR from 'swr';

export function useTodos(projectId: string) {
  const { data, error, isLoading, mutate } = useSWR(
    `/api/projects/${projectId}/todos`,
    fetcher,
    {
      revalidateOnFocus: false,
      onError: (err) => {
        if (err.status === 403) {
          // 権限エラー
          toast.error('アクセス権限がありません');
          router.push('/projects');
        }
      }
    }
  );

  return {
    todos: data,
    isLoading,
    isError: error,
    mutate
  };
}
```
