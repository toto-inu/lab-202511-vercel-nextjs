# 権限設計

## 概要

3階層の権限モデル：**Plan制限 > Tenant Role > Project Role**

## 権限階層

```
┌─────────────────────────────────┐
│  Plan制限（システムレベル）          │
│  - 機能の有効/無効                 │
│  - リソース上限                    │
└─────────────────────────────────┘
              ↓
┌─────────────────────────────────┐
│  Tenant Role（組織レベル）          │
│  - OWNER / ADMIN / MEMBER        │
└─────────────────────────────────┘
              ↓
┌─────────────────────────────────┐
│  Project Role（プロジェクトレベル）   │
│  - ADMIN / EDITOR / VIEWER       │
└─────────────────────────────────┘
```

## 1. Plan制限（第1階層）

### プラン別機能制限

Tenantが契約しているPlanによって、使える機能が制限される。

| 機能 | FREE | PRO | ENTERPRISE |
|------|------|-----|------------|
| プロジェクト数上限 | 3 | 50 | 無制限 |
| ユーザー数上限 | 5 | 50 | 無制限 |
| プロジェクト内Todo上限 | 100 | 1,000 | 無制限 |
| カスタムロール | ❌ | ❌ | ✅ |
| API アクセス | ❌ | ✅ | ✅ |
| 高度なレポート | ❌ | ✅ | ✅ |
| 監査ログ | ❌ | ❌ | ✅ |
| 優先サポート | ❌ | ❌ | ✅ |

### Plan制限の実装

```typescript
// lib/plan-limits.ts
interface PlanLimits {
  maxProjects: number | null; // nullは無制限
  maxUsersPerTenant: number | null;
  maxTodosPerProject: number | null;
  features: {
    customRoles: boolean;
    apiAccess: boolean;
    advancedReporting: boolean;
    auditLog: boolean;
    prioritySupport: boolean;
  };
}

// Plan制限チェック
async function checkPlanLimit(
  tenantId: string,
  limitType: 'projects' | 'users' | 'todos',
  currentCount: number
): Promise<boolean> {
  const tenant = await prisma.tenant.findUnique({
    where: { id: tenantId },
    include: { plan: true }
  });

  const limit = tenant.plan[`max${capitalize(limitType)}`];

  // nullは無制限
  if (limit === null) return true;

  return currentCount < limit;
}
```

## 2. Tenant Role（第2階層）

### ロール定義

#### OWNER（オーナー）
- Tenant内の**全権限**
- プラン変更（将来）
- Tenant削除
- 他のOWNERの任命

**できること**:
- ✅ Tenant設定変更
- ✅ プラン・請求管理（将来）
- ✅ 全ユーザー管理（招待・削除・ロール変更）
- ✅ 全プロジェクト管理（作成・削除・設定）
- ✅ 全プロジェクトの全Todo操作
- ✅ 管理画面へのアクセス

#### ADMIN（管理者）
- ユーザー管理
- プロジェクト作成・管理
- 全プロジェクトへのアクセス

**できること**:
- ✅ ユーザー招待・削除
- ✅ ユーザーロール変更（OWNER以外）
- ✅ プロジェクト作成・削除・設定変更
- ✅ 全プロジェクトの全Todo操作
- ❌ Tenant設定変更
- ❌ プラン変更
- ❌ OWNER任命

#### MEMBER（メンバー）
- 割り当てられたプロジェクトのみアクセス
- プロジェクト内の権限はProjectRoleに依存

**できること**:
- ✅ 割り当てられたプロジェクトへのアクセス
- ✅ プロジェクト内の権限はProjectRoleによる
- ❌ ユーザー管理
- ❌ プロジェクト作成
- ❌ Tenant設定変更

### Tenant Roleの判定

```typescript
// lib/auth/tenant-role.ts
async function getTenantRole(userId: string, tenantId: string): Promise<TenantRole | null> {
  const membership = await prisma.tenantMember.findUnique({
    where: {
      userId_tenantId: { userId, tenantId }
    }
  });

  return membership?.role || null;
}

function canManageUsers(role: TenantRole): boolean {
  return role === 'OWNER' || role === 'ADMIN';
}

function canManageTenant(role: TenantRole): boolean {
  return role === 'OWNER';
}

function canCreateProject(role: TenantRole): boolean {
  return role === 'OWNER' || role === 'ADMIN';
}
```

## 3. Project Role（第3階層）

### ロール定義

#### ADMIN（プロジェクト管理者）
- プロジェクト設定管理
- メンバー管理
- Todo全権限

**できること**:
- ✅ プロジェクト設定変更
- ✅ プロジェクトメンバー追加・削除
- ✅ プロジェクトメンバーのロール変更
- ✅ Todo作成・編集・削除
- ✅ 他人のTodo編集・削除

#### EDITOR（編集者）
- Todo操作全般

**できること**:
- ✅ Todo作成
- ✅ 自分のTodo編集・削除
- ✅ 他人のTodo編集（制限付き）
- ❌ プロジェクト設定変更
- ❌ メンバー管理

#### VIEWER（閲覧者）
- 読み取り専用

**できること**:
- ✅ プロジェクト閲覧
- ✅ Todo一覧閲覧
- ❌ Todo作成・編集・削除
- ❌ メンバー管理

### Project Roleの判定

```typescript
// lib/auth/project-role.ts
async function getProjectRole(
  userId: string,
  projectId: string
): Promise<ProjectRole | null> {
  const membership = await prisma.projectMember.findUnique({
    where: {
      userId_projectId: { userId, projectId }
    }
  });

  return membership?.role || null;
}

function canEditTodo(role: ProjectRole, isOwner: boolean): boolean {
  if (role === 'ADMIN') return true;
  if (role === 'EDITOR') return isOwner; // 自分のTodoのみ
  return false;
}

function canDeleteTodo(role: ProjectRole, isOwner: boolean): boolean {
  if (role === 'ADMIN') return true;
  if (role === 'EDITOR') return isOwner;
  return false;
}

function canManageProjectMembers(role: ProjectRole): boolean {
  return role === 'ADMIN';
}
```

## 権限チェックフロー

### 統合的な権限チェック

**重要**: 権限チェックは以下の順序で実行します:

1. **認証チェック**: ユーザーがログインしているか
2. **Plan制限チェック**: Tenantのプランで機能が使えるか、リソース上限に達していないか
3. **Tenant Roleチェック**: Tenant内での権限があるか
4. **Project Roleチェック**: プロジェクト内での権限があるか（該当する場合）

この順序により、無駄なDB呼び出しを減らし、早期にエラーを返せます。

```typescript
// lib/auth/permission-check.ts
interface PermissionContext {
  userId: string;
  tenantId: string;
  projectId?: string;
  action: string; // 'create_todo', 'edit_todo', 'delete_project', etc.
  resourceOwnerId?: string; // リソースの所有者
}

async function checkPermission(ctx: PermissionContext): Promise<boolean> {
  // 1. 認証チェック（getCurrentUser()で既に実施されている想定）

  // 2. Plan制限チェック
  const tenant = await prisma.tenant.findUnique({
    where: { id: ctx.tenantId },
    include: { plan: true }
  });

  if (!tenant) return false;

  // プラン機能チェック
  if (!checkPlanFeature(tenant.plan, ctx.action)) {
    throw new Error('この機能は現在のプランでは利用できません');
  }

  // リソース制限チェック（create操作の場合）
  if (ctx.action.startsWith('create_')) {
    const resourceType = extractResourceType(ctx.action); // 'create_todo' → 'todos'
    const limitCheck = await checkResourceLimit(ctx.tenantId, resourceType, ctx.projectId);
    if (!limitCheck.allowed) {
      throw new Error(getLimitErrorMessage(resourceType, limitCheck.limit, tenant.plan.name));
    }
  }

  // 3. Tenant Roleチェック
  const tenantRole = await getTenantRole(ctx.userId, ctx.tenantId);
  if (!tenantRole) return false;

  // Tenant OWNER/ADMINは全権限
  if (tenantRole === 'OWNER' || tenantRole === 'ADMIN') {
    return true;
  }

  // 4. Project Roleチェック（プロジェクト関連操作の場合）
  if (ctx.projectId) {
    const projectRole = await getProjectRole(ctx.userId, ctx.projectId);
    if (!projectRole) return false;

    return checkProjectPermission(projectRole, ctx);
  }

  return false;
}

function extractResourceType(action: string): 'projects' | 'users' | 'todos' {
  if (action.includes('project')) return 'projects';
  if (action.includes('user') || action.includes('member')) return 'users';
  if (action.includes('todo')) return 'todos';
  throw new Error(`Unknown action: ${action}`);
}
```

### Server Actionでの使用例

```typescript
// actions/todo.ts
export async function createTodo(projectId: string, data: TodoData) {
  const user = await getCurrentUser();
  const project = await prisma.project.findUnique({
    where: { id: projectId }
  });

  if (!project) throw new Error('Project not found');

  // 権限チェック
  const hasPermission = await checkPermission({
    userId: user.id,
    tenantId: project.tenantId,
    projectId: projectId,
    action: 'create_todo'
  });

  if (!hasPermission) {
    throw new Error('Permission denied');
  }

  // Todo作成
  await prisma.todo.create({
    data: {
      ...data,
      tenantId: project.tenantId,
      projectId: projectId,
      createdById: user.id
    }
  });
}
```

## 特殊なケース

### グローバル管理者

システム全体を管理する特別なユーザー（サポート用）。

```typescript
model User {
  isGlobalAdmin Boolean @default(false)
}

// すべての権限チェックをバイパス
async function checkPermission(ctx: PermissionContext): Promise<boolean> {
  const user = await prisma.user.findUnique({
    where: { id: ctx.userId }
  });

  if (user?.isGlobalAdmin) return true;

  // 通常の権限チェック
  // ...
}
```

### 暗黙的な権限継承

- **Tenant OWNER/ADMIN** → 全プロジェクトでADMIN権限を自動取得
- ProjectMemberレコードがなくても操作可能

```typescript
async function getEffectiveProjectRole(
  userId: string,
  projectId: string
): Promise<ProjectRole> {
  const project = await prisma.project.findUnique({
    where: { id: projectId }
  });

  // Tenant OWNER/ADMINは自動的にプロジェクトADMIN
  const tenantRole = await getTenantRole(userId, project.tenantId);
  if (tenantRole === 'OWNER' || tenantRole === 'ADMIN') {
    return 'ADMIN';
  }

  // 明示的なProjectRoleを確認
  const projectMember = await prisma.projectMember.findUnique({
    where: { userId_projectId: { userId, projectId } }
  });

  return projectMember?.role || null;
}
```
