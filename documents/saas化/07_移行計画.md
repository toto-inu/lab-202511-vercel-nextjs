# 移行計画

## 概要

既存のシンプルなTodoアプリからマルチテナントSaaSへの段階的移行計画。

## 移行戦略

### 原則

1. **段階的な移行**: 一度に全変更を行わず、Phase単位で実装・テスト
2. **データ保全**: 既存データは必ず保持し、デフォルトTenant/Projectに移行
3. **後方互換性**: 既存機能は移行中も動作し続ける
4. **ロールバック可能**: 各Phaseでロールバック手順を用意

### 想定期間

- **全体**: 4-6週間
- Phase 1: 1週間
- Phase 2: 1週間
- Phase 3: 1-2週間
- Phase 4: 1週間
- Phase 5: 1週間

#### 2.3 Middlewareの作成

```typescript
// app/middleware.ts
import { NextResponse } from 'next/server';
import type { NextRequest } from 'next/server';

const publicPaths = [
  '/sign-in',
  '/sign-up',
  '/api/auth',
  '/api/webhooks'
];

export async function middleware(request: NextRequest) {
  const { pathname } = request.nextUrl;

  // Public routesはスキップ
  if (publicPaths.some(path => pathname.startsWith(path))) {
    return NextResponse.next();
  }

  // セッションチェック
  const session = request.cookies.get('better-auth.session_token');

  if (!session) {
    return NextResponse.redirect(new URL('/sign-in', request.url));
  }

  return NextResponse.next();
}

export const config = {
  matcher: ['/((?!_next/static|_next/image|favicon.ico).*)']
};

export async function getTodos(projectId: string) {
  await requireProjectRole(projectId, ['ADMIN', 'EDITOR', 'VIEWER']);
  // ...

export async function createTodo(projectId: string, data: TodoData) {
  const { user, project } = await requireProjectRole(projectId, ['ADMIN', 'EDITOR']);

  // プラン制限チェック
  const limitCheck = await checkResourceLimit(project.tenantId, 'todos', projectId);
  if (!limitCheck.allowed) {
    throw new Error('Todo上限に達しました');
  }

  // 作成
  await prisma.todo.create({
    data: {
      ...data,
      tenantId: project.tenantId,
      projectId,
      createdById: user.id
    }
  });
}

export async function updateTodo(todoId: string, data: Partial<TodoData>) {
  const user = await requireAuth();

  if (!await canEditTodo(user.id, todoId)) {
    throw new Error('権限がありません');
  }

  await prisma.todo.update({ where: { id: todoId }, data });
}
```

##### Project Actions（新規: actions/project.ts）

```typescript
export async function getProjects(tenantId: string) {
  await requireTenantRole(tenantId, ['OWNER', 'ADMIN', 'MEMBER']);

  return await prisma.project.findMany({
    where: { tenantId },
    include: { _count: { select: { todos: true, members: true } } }
  });
}

export async function createProject(tenantId: string, data: ProjectData) {
  await requireTenantRole(tenantId, ['OWNER', 'ADMIN']);

  const limitCheck = await checkResourceLimit(tenantId, 'projects');
  if (!limitCheck.allowed) {
    throw new Error('プロジェクト上限に達しました');
  }

  return await prisma.project.create({
    data: { ...data, tenantId }
  });
}
```

##### Tenant Actions（新規: actions/tenant.ts）

```typescript
export async function switchTenant(tenantId: string) {
  const user = await getCurrentUser();

  const membership = await prisma.tenantMember.findUnique({
    where: { userId_tenantId: { userId: user.id, tenantId } }
  });

  if (!membership) {
    throw new Error('アクセス権がありません');
  }

  await setCurrentTenantId(tenantId);
  revalidatePath('/');
}

export async function getUserTenants() {
  const user = await getCurrentUser();

  return await prisma.tenantMember.findMany({
    where: { userId: user.id },
    include: { tenant: { include: { plan: true } } }
  });
}
```

## データ移行スクリプト

### 既存ユーザーのTenantメンバーシップ作成

Phase 1実行後に一度だけ実行。

**重要**: 既存の`User.role` Enumフィールドに基づいて、適切なTenantRoleを割り当てます。

```typescript
// scripts/migrate-users.ts
import { prisma } from '../app/lib/prisma';

async function migrateUsers() {
  const defaultTenant = await prisma.tenant.findUnique({
    where: { slug: 'default' }
  });

  if (!defaultTenant) {
    throw new Error('Default tenant not found');
  }

  const users = await prisma.user.findMany();

  for (const user of users) {
    const existing = await prisma.tenantMember.findUnique({
      where: {
        userId_tenantId: { userId: user.id, tenantId: defaultTenant.id }
      }
    });

    if (!existing) {
      // 既存のroleフィールドに基づいてTenantRoleを決定
      // 注意: この時点ではまだUser.roleフィールドが存在している前提
      const tenantRole = (user as any).role === 'ADMIN' ? 'OWNER' : 'MEMBER';

      await prisma.tenantMember.create({
        data: {
          userId: user.id,
          tenantId: defaultTenant.id,
          role: tenantRole,
          joinedAt: new Date()
        }
      });

      console.log(`Added ${user.email} to default tenant as ${tenantRole}`);
    }
  }

  console.log('User migration completed!');
  console.log('Next step: Run migration to remove User.role column');
}

migrateUsers();
```

実行:

```bash
bunx tsx scripts/migrate-users.ts
```
